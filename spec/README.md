# Схемы и профиль CBOR

Здесь лежат формы данных, общие для сервера (Go) и клиента (Dart):

| Файл | Что описывает |
| --- | --- |
| `frame.cddl` | Кадр протокола клиент–сервер |
| `signed.cddl` | Конверт `Signed` и подписанные payload: профиль, пост, устройства, приглашение, адреса |
| `json-debug.md` | Как CBOR выглядит в отладочном JSON (`--codec=json`, `yl-decode`) |

Источник правды по смыслу полей — `docs/spec.md`; схемы здесь повторяют его формы
для машин и тестов. Реализации кодека: `server/pkg/codec` и `client/lib/core/codec`.
Общие тестовые векторы — `testdata/vectors/codec` (генерирует `make vectors`).

## Профиль CBOR YeenLink

**Кодирование** детерминированное, одинаковое в Go и Dart:

- ключи словарей отсортированы по RFC 8949 §4.2.1: короче раньше, при равной длине — побайтово;
- длины всегда явные, без счётчика не кодируется ничего;
- целые — в кратчайшей форме;
- числа с плавающей точкой — всегда 64 бита (без укорачивания до 16 и 32 бит);
- теги не используются.

**Разбор** строгий, ошибка относится к одной из категорий ниже. Строки категорий
общие для Go (`codec.ErrKind`), Dart (`CodecErrorKind.wire`) и поля `error`
в недопустимых векторах.

| Категория | Когда |
| --- | --- |
| `malformed` | обрыв, синтаксическая ошибка |
| `trailing` | лишние байты после значения |
| `dup_key` | ключ словаря повторяется |
| `indefinite` | длина без счётчика |
| `tag` | любой тег CBOR |
| `depth` | вложенность больше 16 контейнеров (сам кадр — первый) |
| `size` | массив или словарь больше 16 384 элементов |
| `utf8` | текст не в UTF-8 |
| `simple` | `undefined` и прочие простые значения, кроме `false`, `true`, `null` |
| `int_range` | целое вне int64 (в Dart целые 64-битные со знаком) |
| `key_type` | ключ словаря не текст |
| `frame_shape` | значение не кадр: не словарь, нет `op`, неверные типы, `d` и `e` вместе |
| `json` | значение не переводится в отладочный JSON и обратно |

Неканонический, но корректный вход (ключи не по порядку, целое не в кратчайшей
форме, float32) принимается. Поле `d` кадра хранится сырыми байтами и при
пересылке не перекодируется — подписи считаются от байтов, а не от значения.
