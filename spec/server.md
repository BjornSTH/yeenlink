# Сервер: установка, конфиг, хранение

Детали к разделам `docs/spec.md` «Порты», «Хранение», «Владелец и ключ
администратора» и фазе 2. Код: `server/cmd/ylsrv`, `server/internal/*`.

## Команды

| Команда | Что делает |
| --- | --- |
| `ylsrv init` | Первый запуск: вопросы (или флаги), проверка портов, конфиг, ключ сервера, база, сертификат, ключ администратора. Печатает отпечаток ключа сервера и ключ администратора |
| `ylsrv run` | Работа (для systemd). Если владельца нет и действующего ключа нет — создаёт ключ и пишет в журнал **только путь** к файлу |
| `ylsrv admin-token` | Новый ключ администратора; прежний неиспользованный перестаёт действовать |
| `ylsrv check-ports` | Проверить порты, ничего не меняя |
| `ylsrv version` | Версия |

У всех — `--config` (по умолчанию `/etc/yeenlink/ylsrv.toml`). `run` дополнительно
принимает `--codec=json` (отладка).

Ключ администратора печатается только в терминал. Если вывод не терминал
(`ylsrv admin-token > file`, запуск из скрипта), печатается путь к файлу ключа.

### `ylsrv init`

Флаги: `--name`, `--host`, `--listen`, `--tls`, `--email`, `--http-port`,
`--data-dir`, `--cert-file`, `--key-file`, `--proxy-cert`, `--non-interactive`.
В терминале без `--non-interactive` недостающее спрашивается; иначе берутся
флаги и значения по умолчанию. Конфиг уже есть — отказ (чтобы не перезаписать
ключи).

Режим TLS по умолчанию: `acme`, если `host` — домен, `self-signed`, если IP.
Порт API занят — подсказка про другой порт или режим `proxy`; порт 80
недоступен в режиме `acme` — `http_port = 0`, сертификат через TLS-ALPN-01.

## Конфиг

TOML; неизвестный ключ — ошибка запуска (опечатка не должна молча отключать
настройку). Файл создаётся с правами `0600`.

| Ключ | По умолчанию | Смысл |
| --- | --- | --- |
| `name` | — | Название сервера, 1–64 символа |
| `host` | — | Домен или IP, под которым сервер виден снаружи |
| `listen` | `:443` | Адрес API и WebSocket |
| `data_dir` | `/var/lib/yeenlink` | Ключ сервера, база, ключ администратора, сертификаты (`0700`) |
| `memory_limit_mib` | `80` | `GOMEMLIMIT`, если он не задан в окружении |
| `codec` | `cbor` | `json` — отладка |
| `trusted_proxies` | `[]` | Адреса и сети, которым верим в `X-Forwarded-For` |
| `tls.mode` | `acme` | `acme`, `file`, `self-signed`, `proxy` |
| `tls.email` | — | Почта для Let's Encrypt (необязательно) |
| `tls.http_port` | `80` | Порт HTTP-01; `0` — только TLS-ALPN-01 |
| `tls.acme_ca`, `tls.acme_roots` | — | Другой ACME (тесты на Pebble) и его корни PEM |
| `tls.cert_file`, `tls.key_file` | — | Режим `file` |
| `tls.proxy_cert` | `[]` | Режим `proxy`: PEM сертификатов, которые отдаёт прокси |

## Файлы в `data_dir`

| Файл | Права | Что |
| --- | --- | --- |
| `server.key` | `0600` | Ed25519, PKCS#8 PEM. Права шире `0600` — отказ запуска |
| `yeenlink.db` (+ `-wal`, `-shm`) | `0600` | База |
| `yeenlink.db.bak-vN` | `0600` | Снимок схемы версии N перед миграцией на следующую |
| `admin-token` | `0600` | Ключ администратора, пока им не воспользовались |
| `certs/` | `0700` | Самоподписанный сертификат, кэш certmagic |

Ключ сервера и есть личность сервера: его потеря — новый сервер для всех
клиентов. Резервная копия `data_dir` должна включать `server.key`.

## Режимы TLS

- **acme** — certmagic, Let's Encrypt: TLS-ALPN-01 на порту API и HTTP-01 на
  `http_port`. Порт 80 кроме вызовов ACME только перенаправляет на
  `https://<host>/`. Сертификат получается при запуске (до 3 минут) и
  продлевается сам. DNS-01 — позже (Cloudflare, REG.RU).
- **file** — свой сертификат; замена файла — перезапуск.
- **self-signed** — ECDSA P-256 на 10 лет, создаётся при `init`, отпечаток
  SHA-256 печатается. Доверие держится на ключе сервера (`spec/auth.md`).
- **proxy** — TLS у nginx/Caddy впереди, сервер слушает без TLS (обычно
  `127.0.0.1:8080`). Хеши `tls.proxy_cert` подписываются в challenge; без них
  клиенты предупреждают, что подмена не исключена. После продления сертификата
  у прокси нужен перезапуск `ylsrv` (или прописать оба сертификата на время
  смены). Прокси, подменяющие сертификат (CDN с терминацией TLS), не
  поддерживаются.

## Порты при первом запуске

`init` и `check-ports` пробуют занять порт и сообщают: `свободен`, `занят`,
`нет прав` (порт < 1024 без root или `CAP_NET_BIND_SERVICE`), `ошибка`.

| Порт | Проверка | Обязателен |
| --- | --- | --- |
| TCP `listen` | API и WebSocket | да |
| TCP `http_port` | HTTP-01 (только `acme`) | нет |
| UDP 7882 | голос и видео (фаза 5) | да |
| TCP 7881 | медиа по TCP (фаза 5) | нет |

Проверка видит только локальные порты; закрытый снаружи файрвол она не
обнаружит.

## Хранение

SQLite (`modernc.org/sqlite`, чистый Go — бинарник статический), WAL,
`synchronous = NORMAL`, `foreign_keys = ON`, `busy_timeout = 5000`. Таблицы —
`STRICT`.

| Таблица | Что |
| --- | --- |
| `server_meta` | `name`, `created` |
| `members` | Кто входил: главный ключ, первый и последний вход |
| `roles`, `member_roles` | Роли; встроенные `everyone` (позиция 0, права 0) и `owner` (бит `OWNER`) |
| `device_certs` | Последний сертификат каждого устройства |
| `device_lists`, `profiles` | Последний принятый `Signed` и его `seq` |
| `revoked_devices` | Отозванные устройства |
| `admin_tokens` | SHA-256 ключа, когда создан и использован |
| `server_log` | Журнал сервера: `admin_token.issue`, `owner.change`, … |

### Миграции

- Файлы `server/internal/store/migrations/NNNN_*.sql`, встроены в бинарник;
  версия схемы — `PRAGMA user_version`.
- Перед применением новых миграций к непустой базе версии N — снимок
  `VACUUM INTO yeenlink.db.bak-vN`. Каждая миграция — в своей транзакции.
- База новее бинарника — отказ запуска (откат версии без восстановления
  снимка испортил бы данные).
- `server/internal/store/testdata/schema.sql` — эталон итоговой схемы;
  тест сверяет его с базой после всех миграций. После новой миграции:
  `UPDATE_SCHEMA=1 go test ./internal/store`.

## Ключ администратора

`ylat_` + base62 от 32 случайных байт, ровно 43 символа (старшие разряды
слева, дополнение нулями). В базе — только SHA-256 (пробелы по краям при
вставке отбрасываются), поиск — по хешу. Действует один ключ: новый удаляет
прежние неиспользованные. Протокол — `spec/auth.md`.

## Память

`GOMEMLIMIT` = `memory_limit_mib` (80 МиБ по умолчанию), если не задан в
окружении. В фазе 2 сервер без клиентов занимает ~17 МБ RSS.
