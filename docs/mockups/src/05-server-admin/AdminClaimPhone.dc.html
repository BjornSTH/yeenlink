Ключ администратора
У «Ночного привала» пока нет владельца. Если сервер установили вы, введите ключ администратора: сервер показал его один раз при первом запуске — в консоли и в файле на сервере.
Потеряли ключ? Выпустите новый на сервере:$ ylsrv admin-tokenДоступ к консоли сервера и есть доказательство, что он ваш.
Роль Владельца привяжется к вашему ключу A0D2·5F11. Ключ администратора одноразовый и сгорит сразу после использования.
Готово. Теперь вы Владелец «Ночного привала». Ключ администратора сгорел — для следующей передачи выпустите новый.
