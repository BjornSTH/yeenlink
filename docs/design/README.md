# YeenLink

Self-hosted мессенджер с голосом и стримами: свой сервер на дешёвом VPS, свой профиль, ключ вместо пароля. Интерфейс матовый и тёплый: приглушённый графит, охра гиены и ничего кричащего.

Эта система собрана из макетов главного экрана, голосовых каналов, настроек, онбординга, приглашений и инструментов админа (ПК и Android). Клиент пишется на Flutter; как перенести токены в `ThemeExtension` — в последнем разделе.

## Принципы

1. **Матово, а не неоново.** Никаких насыщенных градиентов и свечения. Глубину дают ступени фона `bg-000` → `bg-400`, а не тени: тени (`shadow-modal`, `shadow-popover`) — только у того, что парит над экраном.
2. **Один акцент.** `accent` (охра гиены) — главная кнопка, активный индикатор, кольцо говорящего, бейдж «ЭФИР». Если на экране две акцентные заливки, одна лишняя.
3. **Честно о технике.** Интерфейс прямо говорит, что происходит: через какой адрес подключились, что увидит сервер, почему 1080p недоступен. Это часть бренда, а не мелкий шрифт.
4. **Спокойные состояния.** Ошибка — это приглушённая красно-коричневая полоса (`err-bg`), а не красный экран.

## Цвет

Две темы: **тёмная матовая** (основная, первая) и **светлая матовая** — тёплая бумага вместо белого.

- Фоны: `bg-100` — окно; `bg-200` — боковые колонки; `bg-300` — карточки и группы; `bg-400` — выбранное; `bg-000` — рельса серверов и поля ввода внутри карточек.
- Текст: `ink` основной, `ink-soft` описания, `muted` подписи, `subtle` — только мелкие служебные надписи и оверлайны. Все четыре держат 4.5:1 на `bg-100`…`bg-300` в обеих темах.
- Акцент: заливка `accent` всегда с текстом `on-accent`. Акцентный **текст** на фоне — `accent-ink` (в светлой теме он заметно темнее заливки, иначе не читается).
- Альтернативные акценты из настроек: `accent-alt-terracotta`, `accent-alt-teal`. Подставляются вместо `accent`, `on-accent` остаётся тёмным.
- Статусы различаются не только оттенком, но и светлотой: `status-online`, `status-idle`, `status-dnd`, `status-offline`. Рядом с точкой статуса в списках всегда есть текст.
- Опасное: заливка `danger` + `on-danger` (кнопка «Покинуть канал»); текстом — `danger-ink`.
- Полосы состояний: тройки `warn-*`, `ok-*`, `err-*` (фон, граница, текст). Янтарная — «переподключаюсь», зелёная — «ключ совпадает», «работает через запасной адрес», красная — «сервер недоступен».
- Роли: `role-master`, `role-player`, `role-guest`, `role-bot` — точка в чипе и цвет имени в списке участников. Админ может задать свои цвета; встроенные приглушены под палитру.
- Баннер по умолчанию: `hyena-banner` с пятнами `hyena-spot`.

> В макетах `subtle` был `#8A8276`; здесь он поднят до `#918A7E`, чтобы держать 4.5:1 на `bg-200`. В коде используйте значение из токенов.

## Типографика

**Manrope** для всего интерфейса (хорошая кириллица, мягкая геометрия) и **JetBrains Mono** для машинного: отпечатки ключей, адреса и порты, коды приглашений, броски кубиков. Оба шрифта — Google Fonts.

Шкала: `display` 44 → `h1` 32 → `h2` 24 → `title` 18 → `body-lg` 15 → `body` 14 → `label` 13 → `caption` 12 → `overline` 11. Заголовки — 800, подписи — 600, текст — 400. `overline` всегда заглавными с разрядкой: «ГОЛОСОВЫЕ», «СЕЙЧАС В СЕТИ».

## Отступы, скругления, размеры

Сетка 4 px: `space-1` 4 … `space-8` 32. Скругления растут с размером объекта: бейдж `radius-xs`, строка канала `radius-sm`, поле `radius-md`, кнопка и карточка `radius-lg`, плитка `radius-xl`, модальное окно `radius-2xl`; всё круглое — `radius-full`. Кнопки: `control-sm` 32, поля `control-md` 42, главные кнопки `control-lg` 48; на телефоне ничего меньше `touch-min` 44.

## Иконки

Контурные, сетка 24 px, обводка 1.8 (2 — для мелких 16 px), скруглённые концы и углы, без заливки. Цвет — `muted` в покое, `ink` при наведении, `accent` в активном состоянии. Маскот-гиена встречается только в логотипе (уши + морда) и в палитре — не в иконках.

## Голос и тексты

- На «вы», коротко, по-русски, без канцелярита: «Подключиться к эфиру», «Пустить», «Покинуть эфир».
- Объясняйте последствия, а не механизм: «Смена ключа сделает недействительными все старые приглашения».
- Честные предупреждения рядом с действием: «Сервер получит ваш публичный профиль и при подключении увидит ваш IP-адрес».
- Цифры — с единицами и пробелом: «720p · 30», «18 / 100 Мбит/с», «6 в сети».

## Компоненты

Кнопка, переключатель, сегментированный выбор, поле ввода, аватар со статусом, чип (роли и реакции), бейдж, полоса состояния, строка канала. У каждого — превью в обеих темах и правила использования.

## Перенос во Flutter

Каждая тема — один `ThemeExtension`, имена полей повторяют токены в camelCase:

```dart
@immutable
class YlColors extends ThemeExtension<YlColors> {
  const YlColors({required this.bg100, required this.bg200, required this.bg300,
    required this.ink, required this.muted, required this.accent, required this.onAccent /* … */});
  final Color bg100, bg200, bg300, ink, muted, accent, onAccent;

  static const dark = YlColors(
    bg100: Color(0xFF1C1B19), bg200: Color(0xFF201E1C), bg300: Color(0xFF24221F),
    ink: Color(0xFFECE6DD), muted: Color(0xFFA39A8D),
    accent: Color(0xFFC9A06B), onAccent: Color(0xFF1C1B19));

  @override
  YlColors copyWith({Color? accent /* … */}) => YlColors(/* … */);
  @override
  YlColors lerp(YlColors? o, double t) => o == null ? this : YlColors(
    bg100: Color.lerp(bg100, o.bg100, t)!, /* … */);
}
// использование: final c = Theme.of(context).extension<YlColors>()!;
```

- Акцент из настроек меняет только `accent` (через `copyWith`), остальное постоянно.
- Шрифты: пакет `google_fonts` или локальные файлы в `pubspec.yaml`; стили шкалы — в `TextTheme` (`display` → `displayLarge`, `h1` → `headlineLarge`, `h2` → `headlineMedium`, `title` → `titleLarge`, `body-lg` → `bodyLarge`, `body` → `bodyMedium`, `label` → `labelLarge`, `caption` → `bodySmall`, `overline` → `labelSmall`).
- Отступы и скругления — константы `YlSpace.s4 = 16`, `YlRadius.lg = BorderRadius.circular(12)`.
- Не используйте стандартные Material-виджеты как есть: оборачивайте их в свои (`YlButton`, `YlToggle`), иначе интерфейс снова будет «как у Google».
