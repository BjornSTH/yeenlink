# Button

Кнопка действия: главная (accent), вторичная (рамка), тихая (без фона), опасная и неактивная.

- **Главная** — заливка `accent`, текст `on-accent`, одна на экран или окно.
- **Вторичная** — прозрачная, рамка `border`, текст `ink`.
- **Тихая** — без рамки, текст `muted`: «Назад», «Отмена», «Пропустить пока».
- **Опасная** — `danger` + `on-danger` только для выхода из голоса; удаление и отвязку пишите текстом `danger-ink`.
- **Неактивная** — `bg-400` + `muted`, и текст объясняет, чего не хватает: «Выберите, что показать».
- Высота `control-lg` (48) в онбординге и приглашениях, `control-sm` (32) в строках. Скругление `radius-lg`.
