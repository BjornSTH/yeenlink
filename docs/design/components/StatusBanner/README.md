# StatusBanner

Полоса под шапкой чата о состоянии соединения.

- Три вида — `warn-*` (переподключаюсь), `ok-*` (работает через запасной адрес), `err-*` (недоступен). Фон, нижняя граница и текст — из одной тройки.
- Всегда говорит, что приложение делает само, и что будет с сообщениями. Адрес — моноширинным справа.
- В красной полосе одно действие: «Повторить сейчас». `role="status"`, без звука и анимации мигания.
