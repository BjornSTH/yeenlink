# Chip

Небольшая метка-таблетка: роль участника или реакция на сообщение.

- Роль — фон `bg-300`, точка цветом роли (`role-*`), текст `ink`.
- Реакция — своя (вы поставили) с рамкой `accent`, чужая — рамка `border`, текст `muted`.
- Не делайте чипы цветными целиком: цвет роли живёт только в точке и в имени.
