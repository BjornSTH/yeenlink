# Input

Текстовое поле с подписью сверху.

- Фон `bg-000`, рамка `border`, в фокусе — `accent`. Высота `control-md`, скругление `radius-md`.
- Подпись — стиль `label` в `ink-soft`, необязательность пишите словами: «О себе (необязательно)».
- Машинный ввод (адреса, коды, секретная фраза) — моноширинным.
