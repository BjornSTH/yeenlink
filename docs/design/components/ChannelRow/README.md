# ChannelRow

Строка канала в боковой колонке.

- Высота 34 (40 на телефоне), скругление `radius-sm`, иконка `#` или динамик в `subtle`.
- Выбранный — фон `bg-400`, текст `ink`. Непрочитанный — `ink` и 700, без точек и счётчиков, если нет упоминаний.
- Голосовой канал, в котором вы находитесь — иконка и таймер в `status-online`; участники — под строкой с отступом.
