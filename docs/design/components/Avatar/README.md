# Avatar

Круглый аватар пользователя с точкой статуса или квадрат со скруглением для сервера.

- Без картинки — инициалы (2 буквы, 800) на приглушённом тёплом фоне, текст `on-accent`.
- Точка статуса снизу справа, с обводкой цветом фона под аватаром.
- Говорящий в голосовом — двойное кольцо: фон, затем `accent`.
- Сервер — квадрат `radius-lg` (в рельсе активный — `radius-lg`, остальные круглые).
