# Toggle

Переключатель вкл/выкл для мгновенно применяемых настроек.

- 44×26, дорожка `border` → `accent`, бегунок `ink`. Всегда с подписью слева в той же строке, пояснение — `caption` в `muted`.
- Заблокированный (права Владельца) — дорожка `status-offline`, строка на 60% прозрачности и пояснение, почему.
- Не используйте для действий с последствиями (бан, смена ключа) — там кнопка с подтверждением.
