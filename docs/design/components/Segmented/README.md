# Segmented

Выбор одного из 2–4 вариантов: качество стрима, частота кадров, вкладки «Все / Ожидают / Баны».

- Подложка `bg-000`, выбранный сегмент `bg-400` + `ink`, остальные `subtle`.
- Недоступный вариант не прячьте: пометьте «· нет» и покажите причину рядом («Сервер разрешает стрим до 720p»).
- Больше четырёх вариантов — это уже список с радиокнопками.
