# Клиент YeenLink (Flutter)

Windows, Linux, Android (затем macOS). Команды — в корневом `Makefile` и `CLAUDE.md`.

- `lib/main.dart` — приложение (в фазе 0 — каркас).
- `lib/main_showcase.dart` — витрина базовых виджетов в тёмной и светлой темах.
- `lib/ui/theme/tokens.g.dart` — генерируется из `docs/design/tokens.json`: `dart run tool/gen_tokens.dart`.
